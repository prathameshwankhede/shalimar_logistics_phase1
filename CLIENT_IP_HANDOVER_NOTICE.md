This repository contains custom, project-specific software developed for the TransFlow Logistics portal. Deliverables include:

* Custom frontend architecture and React user interface components
* Backend Express.js REST API implementations and controllers
* Domain-specific business logic for reverse bidding, rate matrices, in-place re-quoting, and dispatch logging

* Configuration, export utilities, and deployment assets
